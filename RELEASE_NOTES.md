# EverythingFolderSizes v1.0.0 🎉

Initial release of the standalone C++ extension that calculates instant folder sizes in Windows File Explorer using **[Everything (Voidtools)](https://www.voidtools.com/)**.

### 📦 Installation
1. Extract **`EverythingFolderSizes-v1.0.0-x64.zip`** to a permanent folder.
2. Open PowerShell as Administrator and run:
   ```powershell
   sudo powershell -ExecutionPolicy Bypass -File .\install_autostart.ps1
   ```
3. Open File Explorer in Details view and press **`F5`**.

> See full configuration steps in [README.md](https://github.com/JoeAlex97/EverythingFolderSizes#readme).
